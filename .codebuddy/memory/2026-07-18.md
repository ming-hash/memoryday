## Session 2 修复 (7月18日 第2轮)
### 已修复的 Bug
1. **Redis 缓存配置（关键阻塞）**：`settings.py` 和 `settings/production.py` 的 cache BACKEND 从 `django.core.cache.backends.redis.RedisCache` 改为 `django_redis.cache.RedisCache`。Django 内置的 RedisCache 不支持 `CLIENT_CLASS` 参数，导致缓存完全不可用。
2. **SMS 验证码登录失败**：`UserLoginSerializer` 在 serializer 层调用 `authenticate()` 检查密码哈希，SMS 验证码（6位纯数字）永远不会通过密码哈希校验，错误在到达 view 前已被 serializer 拦截。修复：将 `authenticate()` 从 serializer 移除，改为纯字段校验，所有认证逻辑移到 `views.login_user()` 中统一处理。
3. **Token 存储读取不一致**：`StorageService.setToken()` 将 token 包装为 `{data: token, expire, timestamp}` 存储，但 `utils/api.js`、`utils/wxcloud-api.js`、`services/cosService.js` 使用 `wx.getStorageSync('token')` 直接读取，得到包装对象而非 token 字符串，导致 Authorization header 为 `Bearer [object Object]`。修复：所有文件改用 `StorageService.getToken()` 正确解包。
4. **COS 服务降级中的 token 问题**：`cosService.js` 的 `uploadImageToLocal()` 方法同样使用了 `wx.getStorageSync('token')`，已修复为 `StorageService.getToken()`。
